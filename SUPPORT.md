# Support

[中文说明](SUPPORT.zh-CN.md)

Tinkora is maintained on a best-effort basis without a response-time SLA.

For a non-sensitive usage or integration question, first read the project's
documentation and search its existing issues, then use the
[question form](.github/ISSUE_TEMPLATE/question.yml). Include the affected
version or commit, environment, context, and resources already checked. Use the
matching bug or documentation form when the behavior is reproducibly wrong or
the documentation itself has a specific gap.

Organization Discussions and a dedicated support channel are not configured.
Do not assume an unlisted chat room, email address, or social account is an
official support channel.

The question form and all other public support channels must contain no secret,
personal data, proprietary content, or private log. Suspected vulnerabilities
follow [SECURITY.md](SECURITY.md). Sensitive harassment and Code of Conduct
reports follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Neither type belongs in
a public form, and their private intake channels are not yet configured.
