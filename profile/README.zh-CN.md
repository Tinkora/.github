# Tinkora

**人能直接用，Agent 也能调用。**

[English](README.md)

Tinkora 为开发者和 AI Agent 构建聚焦、开源的实用工具。项目重视清晰的工作流、在隐私敏感场景中
进行本地处理、稳定的机器可读契约，以及可以通过 CI 验证的实际行为。

## 项目

公开项目目录正在审查中。只有实现、文档、安全边界、维护状态和公开 URL 均已验证的仓库，才会列在
这里。仅有 tool schema 或规划文档，不会被视为可由 Agent 调用的产品。
